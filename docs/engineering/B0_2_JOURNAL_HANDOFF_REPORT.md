## Design and source references

[Roadmap B PA2](../roadmap/ROADMAP_B_PA2_PRODUCTION_RUNTIME_V2_0.md), [ADR B001](../architecture/ADR_B001_BRAIN_LED_INDEPENDENT_RUNTIME.md), merged B0.1/PR #320 [handoff](B0_1_DESIGN_HANDOFF_REPORT.md), [contracts](../../src/ai_commerce/production_runtime/contracts.py), [pure reducer](../../src/ai_commerce/production_runtime/state_machine.py), [tests](../../tests/test_b0_production_contracts.py) and [owner manifest](../../work_items/mt01-components/b0-1.json) were read as frozen source. CreativeDirective.v1, BrainDecision.v1 and ProductJourneyReceipt.v1 remain unchanged.

[journal.py](../../src/ai_commerce/production_runtime/journal.py) uses Python stdlib SQLite with an explicit absolute path, exclusive create, separate existing-only open, schema/application version, exact schema comparison, integrity checks, DELETE rollback journal and synchronous=FULL on writer connections. Every mutation uses BEGIN IMMEDIATE and validates the immutable chain and indexes before commit. Creation failure leaves a file requiring inspection, never a silent reset. Reopening missing, empty, corrupt, foreign or unsupported schema journals HOLD.

Four append-only tables hold database identity, canonical event records, immutable journey registration and unique semantic intent indexes. UPDATE/DELETE triggers reject mutation; replay independently cross-checks every index against records. Each global record hashes canonical payload, previous record hash, sequence, source/journal identity, journey, owner, fencing generation, explicit logical time and event ID. Journey sequences use expected-sequence CAS; event IDs are database-wide unique. Bounds limit TTL to 300 logical units, records to 8192 and events per journey to 256. No migration, pruning, automatic reset or background loop exists.

The lease is reconstructed from immutable acquire/renew/release events. Acquisitions require a never-reused session owner; generation increases on every acquisition. Every write rechecks current token and expiry inside the same write transaction. Logical time cannot regress. Caller time is a deterministic offline input, not authenticated real-world expiry. Takeover confers coordination rights only. No external system fencing is implemented or claimed.

Original directives remain externally held and bound by ref, version, contract digest and complete-record SHA; initial product_ref=null is valid. No freeform creative brief, Brain rationale, raw customer payload, cookie, token or credentials are copied into SQLite. The closed payloads accept only coordination enums, bounded opaque IDs and hashes. Opaque refs are caller-redacted identifiers; this is not a general DLP system and cannot detect a secret intentionally disguised as an identifier.

[A08 assisted publication/export](../../src/ai_commerce/distribution/assisted.py), [A09 import provenance](../../src/ai_commerce/analytics/importer.py), [A15 retry evidence](../../src/ai_commerce/operations/retry_guard.py), [A15 costs](../../src/ai_commerce/operations/cost_ledger.py) and [A16 settlement review](../../src/ai_commerce/settlement/review.py) retain their business truth. Their authenticity/freshness remains unverified until native validators and independent ingress are separately integrated. No cross-ledger atomicity is claimed.

## Recovery and effect boundary

[recovery.py](../../src/ai_commerce/production_runtime/recovery.py) reopens read-only and verifies schema, chain, sequence, indexes, lease and source identity. With the separately supplied exact pinned directive it reconstructs INPUT_ACCEPTED and safe START/OUTPUT_READY/QA_PASSED/HOLD/STOP events using B0.1 transition with its default empty authority context. Without that directive, replay reports HOLD or preserves an already reserved UNKNOWN_EFFECT. No state text/snapshot is persisted or trusted. Brain, Human, provider, release and completion events cannot enter this cut.

At WAIT_BRAIN a deliberately modeled PUBLISH reservation can be committed without inventing a RELEASE_REQUESTED event or authority context. It grants no execution rights. Stable target identity includes action/provider/account/surface/content SHA and excludes caller event ID, journey and supplied effect key. The deterministic key and global semantic uniqueness reject a rekeyed reservation for the same target, even across journeys. One reservation per journey prevents revision/retry under another target. Canonical owner-assigned refs are assumed: alias/account canonicalization outside those refs is not proven.

`reserve_intent` returns only after COMMIT. There is no adapter callback. A crash before commit leaves no intent; a crash after commit, before a modeled call, after the modeled call before receipt, or after modeled receipt commit retains UNKNOWN_EFFECT and the original request/key. The ambiguity between reservation and call cannot be resolved from local control flow. Idempotent read-only replay never executes or resubmits anything.

Offline observation records distinguish UNKNOWN, NO_EFFECT and CONFIRMED as modeled claims and preserve their evidence type/ref/SHA. SYNTHETIC_FIXTURE is a test input; HUMAN_SUPPLIED and PROVIDER_ATTESTED labels also confer no actual attestation. All reserved effects remain UNKNOWN, with provider_verified=false and may_retry=false. Only a future independently authenticated provider observation could authorize a real outcome; B0.2 exposes no verified=True/context ingress. A second contradictory observation is denied without rewriting the first. There is no presumed global exactly-once provider guarantee.

A caller-retained Checkpoint detects a missing tail, mismatching prefix or rolled-back generation relative to that anchor. A consistent rollback with no independently retained anchor is indistinguishable from its earlier historical database. Malicious same-SID replacement of both journal and anchor, secure unattended credential custody, independent anti-tamper and anti-rollback proof remain **NOT_PROVEN**. Hashes are not signatures.
