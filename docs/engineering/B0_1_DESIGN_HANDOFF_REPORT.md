LangGraph optional interrupt/checkpoint adapter only after measured complexity; Temporal deferred; OpenMontage selective YAML stage/tool ideas only, no AGPL copy/import; Postiz separate future draft-only adapter; Ruflo inspiration only after measured benefit.
- Three schemas and dataclass/JSON bridge are closed and side-effect-free; pure reducer declares all requested states, denies replay/UNKNOWN/unknown state promotions, requires separate trusted Brain/Human/provider/rights inputs, and preserves evidence pins. The seven old consumer files in the new manifest are **read-only integration boundaries**, not existing imports of this new package.
- **No authority verifier is implemented.** VerificationContext is a trusted input seam, not an attestation API; constructing its dataclasses in a test does not verify anyone. Event data/schema labels/hashes cannot supply that context. Pure snapshots assume a trusted caller/journal; exposing arbitrary caller-created context/snapshots as production authorization would violate this design.
- **No SQLite/worker/scheduler/recovery service is implemented.** Unknown effect branches are pure models. Cross-journey dedup, fencing enforcement, budget reservation, directive revision, anti-rollback and actual provider reconciliation are B0.2+ requirements, not completed features.
- Brain is current ChatGPT chat with default Human-attended WAIT_BRAIN receipt; future verified CDP/Wake is optional and unproven. No paid media API, Postiz/OpenMontage/Ruflo deployment, secrets, HostOps/CDP effect, live publish, order, settlement or customer outcome was performed.
